Quienes enseñaron

Cada palabra de Piko dice de quién viene.

    Tus datos

    Cómo cuidamos lo que aportás

    • Lo que escribís se guarda tal cual. Las variantes y las formas de escribir de cada persona no se corrigen: son datos.
    • Tu contacto nunca se publica. Sólo el nombre o apodo con el que elegiste aparecer, tu rol y tu comunidad.
    • Se usa para enseñar la lengua en Piko. Cualquier otro uso requiere consultar a quienes aportaron y a sus comunidades.
    • Un hablante decide. Un modelo de lenguaje busca patrones y los propone como hipótesis; los hablantes dicen qué es correcto. Cómo trabajamos.

    El servidor

    Dónde viven tus aportes

    La app no necesita internet. Lo que sí está en un servidor son las encuestas, y viven en Azure, armadas para que tus respuestas lleguen cifradas y nadie de afuera pueda tocar la base de datos.

    1. Tu teléfono habla con Nginx, por HTTPS. Es la única puerta abierta a internet. Todo viaja cifrado, con certificado de Let's Encrypt.
    2. Nginx le pasa el pedido a la API. Corre en su propio contenedor Docker, sin ningún puerto hacia afuera, y solo acepta pedidos del navegador que vengan de los sitios de Piko (CORS).
    3. La API guarda en la base de datos. Otro contenedor, en una red interna: desde internet ni siquiera se ve que existe.
    4. El servidor no se maneja como root. Se entra con un usuario normal y una llave, nunca con contraseña. Las claves secretas no están en el código: viven solo en el servidor. Y Azure avisa si la API deja de responder.
