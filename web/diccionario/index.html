Las etiquetas

Una lengua viva se dice de muchas formas

El miskito cambia de un lugar a otro y de una persona a otra. Ninguna forma es «la correcta»: el diccionario las guarda todas. Estas etiquetas te avisan cuando una palabra tiene más de una forma.

Sobre la voz. El botón celeste usa la voz en español de tu teléfono o computadora, para mientras conseguimos grabaciones de hablantes de miskito. Puede sonar un poco distinto a como se dice de verdad.
